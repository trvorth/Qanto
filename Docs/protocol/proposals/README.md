# Qanto Protocol Proposals

This directory contains Quality Improvement Proposals (QIPs) for the Qanto protocol.

## Active Proposals

- [QIP-001](./QIP-001-treasury-management.md) - Treasury Management System (IMPLEMENTED)
- [QIP-002](./QIP-002-v2-protocol-boundary.md) - V2 Protocol Boundary and Canonical Records (REQUIRES PROTOCOL APPROVAL)

## Proposal Process

1. **Draft**: Community discussion and technical review
2. **Review**: Formal review by protocol maintainers
3. **Vote**: Token-weighted voting by staked validators
4. **Activate**: Implementation in next protocol upgrade

## QIP Categories

- **Consensus**: Changes to core consensus rules
- **Networking**: P2P protocol and gossip improvements
- **Execution**: Transaction processing and smart contract updates
- **Economics**: Tokenomics, fee structures, and treasury
- **Governance**: Voting mechanisms and proposal processes
- **Privacy**: Zero-knowledge proofs and confidential transactions
- **Interoperability**: Cross-chain bridges and asset transfers
