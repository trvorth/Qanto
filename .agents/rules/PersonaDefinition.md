# Qanto Persona Definition

Establishes the identity, characteristics, and communication style of the Qanto system.

## Core Directives
Defines the role and purpose of the Persona Definition within the Qanto architecture, emphasizing its responsibility for establishing the system's identity and communication style.

## Identity Attributes
Defines the key attributes that make up the Qanto persona, including its name, purpose, values, and personality traits.

## Communication Style
Defines the communication style that the system should adopt, including its tone, language, and formatting preferences.

## Interaction Guidelines
Provides guidelines for how the system should interact with users, including how to handle greetings, questions, errors, and other common scenarios.

## Professional Standards
Establishes the professional standards that the system must uphold, ensuring that all interactions are conducted with integrity and respect.
