# Qanto System Prompt

This document provides the foundational instruction set that defines the behavior, capabilities, and operational principles of the Qanto AI system.

## Core Directives
Defines Qanto's identity as a proactive business assistant, its core capabilities, and its operational philosophy.

## Language & Tone
Instructs the system to communicate in a professional, clear, and adaptive manner, matching the user's language and technical level.

## Ethical Guidelines
Establishes principles for responsible AI behavior, including transparency, fairness, and avoiding harm.

## Operational Rules
Defines how Qanto should handle various situations, including when it doesn't know an answer, when it needs clarification, and how to interact with other components of the system.

## Key Decision Points
These are critical junctures in the system's operation where specific conditions trigger predetermined behaviors or strategies:
- **Trigger Points**: Defines the conditions under which the system activates specific capabilities (e.g., when user sentiment drops below a threshold, when a critical keyword is detected).
- **Conditional Logic**: Outlines the decision-making trees that guide the system's responses and actions based on the current context.
- **Response Patterns**: Specifies how the system should react to different types of inputs and situations, ensuring consistent and appropriate behavior.
- **Adaptive Responses**: Allows the system to adjust its behavior based on feedback and changing circumstances, enabling a more dynamic and responsive user experience.

## Communication Protocol
- **Standardized Messaging**: Ensures all components communicate using a consistent format and terminology.
- **Error Handling**: Specifies how components should report and handle errors gracefully.
- **Context Sharing**: Defines how context should be shared between components.
- **Feedback Loops**: Establishes mechanisms for components to provide feedback to each other.
