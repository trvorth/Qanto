# RAG System Prompt

Provides the foundational instructions and guidelines for the Retrieval-Augmented Generation (RAG) component of the Qanto system.

## Core Directives
Defines the role and purpose of the RAG system within the Qanto architecture, emphasizing its responsibility for information retrieval and context provision.

## Retrieval Strategy
Details how the RAG system should retrieve information from the knowledge base, including search algorithms, ranking criteria, and context selection strategies.

## Response Generation
Outlines how the RAG system should generate responses based on the retrieved information, including formatting requirements, response structure, and integration with other system components.

## Context Management
Defines how the RAG system should manage context, including how to handle long-term memory, session history, and user preferences to provide relevant and personalized responses.
